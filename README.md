# TP Système Multi-Agents (IA04)

Ce projet répertorie tous les TPs fait durant la matière Système multi-agents IA04

Tous les TPs sont fait en Go, voici un lien du [tuto](https://go.dev/doc/tutorial/).

# Utilisation

Voici comment exécuter les différents programmes, vous devez d'abord installer Go

    cd tp1                      // Se diriger dans le tp souhaité

    go run tp1/cmd/hello/.      // Lancer le module souhaité 

# Developpement

Voici quelques commandes utiles afin de développer dans de bonnes conditions

    go mod init tpx             // Init un nouveau module

    go fmt <filename/repo>      // Formater le fichier

    go run <filename/repo>      // Exécuter le code

    go build <filename/repo>    // Construire l'exécutable

    go install <filename/repo>  // L'executable est ajouté dans votre /bin
